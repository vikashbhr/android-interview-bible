# 🚀 Getting Started — Android Interview Preparation Guide

Welcome to the **Android Interview Bible**.

This section helps you prepare for Android interviews in the correct order before diving into Kotlin, Jetpack Compose, Coroutines, or System Design.

Think of this as your interview playbook.

---

# 🎯 Who Is This Guide For?

This repository is designed for Android developers at different experience levels.

| Experience | Goal |
|------------|------|
| **0–2 Years** | First Android job, Kotlin fundamentals, Android SDK basics. |
| **2–4 Years** | Product company interviews, MVVM, Coroutines, Room, Navigation. |
| **4–6 Years** | Jetpack Compose, Performance, Testing, Architecture. |
| **6–8 Years** | Senior Android Engineer interviews, Modularization, Hilt, Android Internals. |
| **8–10+ Years** | Staff Engineer interviews, Compose Runtime, KMP, System Design, Machine Coding, Leadership. |

# 🏆 Android Interview Process (Product Companies)

## Typical Interview Pipeline

| Round | Focus |
|-------|-------|
| Resume Screening | Experience, projects, GitHub. |
| Technical Round 1 | Kotlin, Android SDK, Coroutines, Compose. |
| Technical Round 2 | Architecture, Android internals, debugging. |
| Machine Coding | Build a feature using Compose. |
| System Design | Design a scalable Android application. |
| Behavioral | Leadership, ownership, collaboration. |
| Hiring Manager | Project discussion and decision making. |
